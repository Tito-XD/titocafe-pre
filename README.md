# Tito's Cafe | 头头咖啡屋

> 原创 Furry 角色企划 × 周边展示站

## 预览

本地直接打开 `index.html` 即可预览，无需构建。

## 部署

本站为纯静态页面，可直接部署到 [Netlify](https://netlify.com)：

1. 将此仓库连接到 Netlify
2. Build command 留空
3. Publish directory 填 `.`（根目录）
4. 或直接使用根目录下的 `netlify.toml`，已配置好
